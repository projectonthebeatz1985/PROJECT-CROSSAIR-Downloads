# PROJECT CROSSAIR

**Retro Arcade Edition — FiveM Crosshair Utility**

PROJECT CROSSAIR is a Windows gaming utility designed for FiveM and GTA V.

### Features
- Custom crosshair styles
- Upload your own crosshair images
- Adjustable size, color, thickness and opacity
- Transparent always-on-top crosshair overlay
- System tray support
- Retro arcade interface

Download the Windows installer from the Releases section.

Designed for Windows 10 and Windows 11.
